# Preschool Enrollment Analytics Dashboard

## Overview

This repository showcases a **group data analytics project** developed for an early childhood education centre in Malaysia. The project focused on transforming raw operational data into meaningful business insights through data preprocessing, exploratory data analysis (EDA), and interactive dashboard development.

> **Note:** The original dataset is not included in this repository due to confidentiality and privacy agreements.

---

## My Contribution

Although this was a **group project**, my primary responsibility was to **design and develop the interactive dashboard**, transforming the processed data into clear visual insights for decision-making.

The project workflow included:

- Data collection
- Data cleaning
- Data preprocessing
- Data transformation
- Exploratory Data Analysis (EDA)
- Dashboard design and development *(My Contribution)*

---

## Dashboard Overview

The dashboard consists of **four interactive pages**.

### 1. Overview

Provides a high-level summary of key business metrics, including:

- Total Students
- Average Parent Income
- Student Distribution by Branch
- Popular Program Categories
- Income Category Distribution

---

### 2. Student Insights

Focuses on student demographics and enrollment trends, including:

- Student Enrollment Trend by Year
- Students by Age
- Student Status Distribution
- Student Enrollment by Branch

---

### 3. Parent Insights

Provides insights into parent demographics and marketing effectiveness, including:

- Marketing Channel Effectiveness
- Parent Income Distribution
- Father's Occupation Breakdown
- Mother's Occupation Breakdown

---

### 4. Combined Insights & Recommendations

Brings together key findings from both student and parent analyses and presents actionable recommendations to support strategic planning and operational decision-making.
